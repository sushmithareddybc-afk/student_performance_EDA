# Student Performance Analysis using EDA

## Project Description
This project performs Exploratory Data Analysis
on a Student Performance Dataset using Python.

## Objectives
- Analyze student academic performance.
- Identify patterns and trends.
- Understand relationships between variables.
- Visualize student performance.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset Information
- Total Records: 395
- Total Columns: 33

## Data Analysis
- Data cleaning
- Missing value analysis
- Duplicate checking
- Statistical analysis
- Correlation analysis

## Visualizations
- Bar Chart
- Histogram
- Scatter Plot
- Correlation Heatmap

## Expected Outcome
Develop analytical thinking and data
exploration skills.

## Conclusion
The project explores student academic
performance and identifies relationships
between different student characteristics
and academic grades.
